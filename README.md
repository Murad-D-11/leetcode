# LeetCode Solutions

## Inspiration

I created this repository to document my journey of becoming a stronger software engineer through consistent problem solving. Rather than simply collecting accepted solutions, my goal is to understand the underlying algorithms, data structures, and design patterns behind each problem.

As I prepare for software engineering internships and continue developing larger projects, I see LeetCode as an opportunity to strengthen my analytical thinking, write cleaner code, and improve my ability to solve unfamiliar problems efficiently.

## Languages

This repository primarily contains solutions written in:

* **C++** – My primary language for algorithms and performance-oriented programming.
* **Java** – Used to strengthen my understanding of object-oriented programming and to prepare for technical interviews where Java is commonly used.
* **Python** – Used occasionally for concise implementations and exploring different approaches.

As I continue learning new languages and technologies, I may revisit problems to compare syntax, performance, and programming paradigms.

## What I've Learned So Far

Working through LeetCode has taught me much more than individual algorithms. Some of the key lessons include:

* Breaking complex problems into smaller, manageable steps before writing code.
* Recognizing recurring patterns such as two pointers, sliding window, binary search, recursion, dynamic programming, graphs, and trees.
* Analyzing time and space complexity to choose efficient solutions.
* Writing cleaner, more readable, and maintainable code instead of focusing solely on getting an accepted submission.
* Learning to debug edge cases and think carefully about input constraints.
* Understanding when multiple valid approaches exist and evaluating the trade-offs between them.
* Developing persistence by revisiting problems and improving previous solutions rather than settling for the first working implementation.

This repository reflects my progress as a programmer, and I expect both my coding style and problem-solving approach to continue evolving over time.
